# Synthesis

This domain deals in the means of synthesis of tokens by a model for some end. An LLM is a computer algorithm capable of synthesizing textual output that encodes semantics; it is able to do so in the general sense by having its output tokens tuned by their priors. The workflows in this domain aim to manipulate, filter & transform this synthesis.
