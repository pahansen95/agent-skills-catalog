# Epistemics

Workflows for handling the truth-status of a document's claims: where a claim's
support comes from, whether it holds, and how the attribution is recorded.

> **Status: in development.** This domain currently holds a single skill. Its
> scope may split into separate skills if usage warrants; until then the
> concerns live as steps and settings in one workflow. Versions are `0.y.z`.

## Skills

- **[grounding](skills/grounding/SKILL.md)** — make factual claims traceable:
  find each claim's support, optionally test it, record the attribution, and
  never let a claim pass silently unsupported.
