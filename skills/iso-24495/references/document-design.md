# Document design

Use this reference when a document's structure or presentation affects whether readers can find, compare, navigate, or act on complex information. Start from reader tasks and the document's medium: a digital guide, print form, report, contract, and reference manual need different navigation and visual support.

Create a visible hierarchy that reflects the information's real relationships. Use labels that help readers predict where an answer will be, group related material, and place prerequisites before dependent instructions. Provide navigation aids when the document's size or use makes them helpful, and keep labels consistent between those aids and the content they lead to.

Select a presentation that fits the relationship: steps for an ordered procedure, a table for meaningful comparison, a diagram for spatial or process relationships, and prose for nuance that would be lost in a compact format. Use spacing, typography, emphasis, and callouts consistently so readers can recognize their meaning. Do not distort or omit content to make a layout look tidy.

Treat accessibility as a reader need throughout, while using the applicable accessibility requirements and technical guidance for implementation details.
